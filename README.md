# SnipCue

SnipCue 是一款 macOS 菜单栏截图工具。可截取全屏、窗口、区域与滚动内容，并在截图后标注、提取文字、翻译、复制或保存。

- [官网与下载](https://indenscale.github.io/SnipCue/)
- [两分钟上手指南](https://indenscale.github.io/SnipCue/guide.html)
- [v0.1.1 发布页](https://github.com/IndenScale/SnipCue/releases/tag/v0.1.1)
- [DMG 安装包](https://github.com/IndenScale/SnipCue/releases/download/v0.1.1/SnipCue-0.1.1-macos-arm64.dmg)

支持 macOS 15 或更新版本的 Apple 芯片 Mac。当前公开包为本地签名版本，尚未经过 Apple 公证；首次打开请参照[使用指南](https://indenscale.github.io/SnipCue/guide.html#install)。

本仓库用于发布官网和安装包。安装包作为 GitHub Release 附件提供。
